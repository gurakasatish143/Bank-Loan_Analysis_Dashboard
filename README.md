# Bank Loan Analysis Dashboard

## Project Overview
This project analyzes bank loan data using Excel to understand loan performance and customer details.

## Key KPIs
- Total Loan Amount
- Total Loan Applications
- Average Interest Rate
- Average DTI
- Good Loan Percentage
- Bad Loan Percentage

## Dashboard Analysis
The dashboard includes:
- Loan status analysis
- Loan purpose analysis
- State-wise loan analysis
- Monthly loan trends
- Home ownership analysis
- Employee length analysis

## Tools Used
- Microsoft Excel / WPS Office
- Pivot Tables
- Charts
- Data Analysis
